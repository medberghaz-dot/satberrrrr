متطلبات التشغيل

قبل تحميل واستخدام المشروع، تأكد من تثبيت:

Node.js (18+)

تحميل من nodejs.org

npm أو pnpm

يأتي npm مع Node.js مباشرة

خطوات التثبيت بسرعة

  1. استخرج ملف arise-nextjs.tar.gz
  2. افتح Terminal/CMD في المجلد
  3. اكتب: npm install
  4. اكتب: npm run dev
  5. افتح: http://localhost:3000
