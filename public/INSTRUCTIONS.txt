📥 خطوات التحميل والتثبيت:

1️⃣ استخرج الملف:
   - اضغط زر الماوس الأيمن على arise-nextjs.tar.gz
   - اختر "Extract All" أو "Extract Here"
   - أو استخدم: tar -xzf arise-nextjs.tar.gz

2️⃣ افتح Terminal/Command Prompt:
   - Windows: اضغط Win+R واكتب cmd
   - Mac/Linux: افتح Terminal
   - انتقل إلى المجلد المستخرج

3️⃣ ثبت المشروع:
   pnpm install
   أو
   npm install

4️⃣ شغّل خادم التطوير:
   pnpm dev
   أو
   npm run dev

5️⃣ افتح المتصفح:
   http://localhost:3000

❓ حل المشاكل الشائعة:

مشكلة: "command not found: pnpm"
الحل: استخدم npm بدلاً منه
      npm install
      npm run dev

مشكلة: "Port 3000 already in use"
الحل: الخادم يعمل بالفعل أو استخدم منفذ مختلف:
      PORT=3001 npm run dev

مشكلة: "npm: command not found"
الحل: أعد تثبيت Node.js من nodejs.org
